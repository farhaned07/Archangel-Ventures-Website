# Workshop Package

This folder contains the materials used to run the AP Accelerator discovery and design workshop.

## Purpose

Make it easy for the client team to understand the process, align on scope, and approve the first implementation.

## Files

- [Workshop agenda](./workshop-agenda.md)
- [Process mapping worksheet](./process-mapping-worksheet.md)
- [Discovery questions](./discovery-questions.md)

## Workshop outcome

A clear picture of the current process, the desired future process, the owners, the data sources, and the client configuration required for deployment.
