# Workshop Agenda

## AP Accelerator Discovery Workshop

### 1. Process walk-through
Understand how invoices arrive, move, and get approved today.

### 2. Systems review
Identify the mailbox, SharePoint, ERP, Teams, and reporting tools in use.

### 3. Data review
Identify where vendors, POs, invoices, and approvals are stored.

### 4. Rules review
Confirm approval thresholds, exceptions, and tolerance rules.

### 5. Future state
Agree the target process and the first pilot scope.

### 6. Next steps
Produce the client configuration file and implementation plan.
