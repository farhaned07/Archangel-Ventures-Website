# AP Accelerator — Discover

## Objective
Understand how the client actually handles invoices before automation starts.

## Questions to answer

- Where do invoices arrive?
- Who owns the AP process?
- Which SharePoint library stores invoices today?
- Which vendor and PO sources are authoritative?
- What approvals exist?
- What exceptions happen most often?
- What should be automated first?

## Outputs

- Current state process map
- Stakeholder list
- System inventory
- Data ownership matrix
- Gap register
- Priority scorecard
- Client configuration draft

## Minimum workshop agenda

1. Process walkthrough with AP
2. Review of invoice sources and exceptions
3. Review of systems and data owners
4. Review of approval rules
5. Review of reporting and audit needs

## Deliverable rule

If the client cannot explain the process in a few minutes, the process is not ready for automation.
