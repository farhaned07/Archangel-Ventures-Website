# AP Accelerator — Build

## Objective
Implement the approved design in Microsoft 365.

## Build components

- Power Automate flow
- SharePoint document library
- Dataverse tables
- AI Builder extraction model
- Teams adaptive card approval
- Power BI dashboard

## Build sequence

1. Create environment variables
2. Create SharePoint structure
3. Create Dataverse tables
4. Build invoice ingestion flow
5. Add AI extraction
6. Add validation rules
7. Add approval routing
8. Add exception handling
9. Add audit logging
10. Add reporting dataset

## Engineering rule

The solution should be easy to support by a small team after go-live.

## Deliverable rule

Every flow step must have a clear purpose and a clear owner.
